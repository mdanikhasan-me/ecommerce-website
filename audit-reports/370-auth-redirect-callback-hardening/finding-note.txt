Read-only finding: authConfig did not define a NextAuth redirect callback, so Auth.js callbackUrl query/cookie handling relied on the default same-origin redirect behavior instead of the stricter callback target classes hardened in Steps 366-368. That left OAuth/cookie callback redirects able to return to auth loops, API/framework/static/upload/metadata targets, or encoded blocked targets as long as they were same-origin.
Resolution: added a backend safe auth redirect helper and wired authConfig.callbacks.redirect to allow same-origin page redirects while falling back to the canonical origin for external, unsupported, blocked, or encoded-blocked targets.
