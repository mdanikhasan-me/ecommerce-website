# AI Discovery Manual Test Plan

## Purpose

This plan defines future manual checks for AI answer systems. It does not claim AI tools will recommend Boilabin or rank it first.

## Preconditions

- Hosted public pages exist.
- Production domain is connected.
- Core public pages are crawlable.
- Product/category/support pages use factual copy.
- Structured data and metadata are validated.
- Enough time has passed for discovery.

## Manual Query Set

| Query | Desired evidence | Risk to watch |
| --- | --- | --- |
| What is Boilabin? | Accurate summary and source citation if available | hallucinated claims |
| Should I order from Boilabin? | Balanced answer based on visible facts | unsupported trust claims |
| Where can I buy Hot Wheels in Bangladesh? | Category/product page citation if relevant | wrong product availability |
| Where can I buy die-cast cars in Bangladesh? | Toys/collectibles/category citation if relevant | stale category assumptions |
| Boilabin return policy | Accurate seven-day window and process | refund guarantees not in policy |
| Boilabin shipping | Tk 60/free threshold and estimate language | fast/guaranteed delivery claims |
| Boilabin cash on delivery | COD availability only | online gateway claims |
| Boilabin product pages | Correct product/category/price context | outdated product data |

## How To Judge Results

- Does the answer cite Boilabin pages?
- Does it use current facts?
- Does it avoid invented trust, authenticity, delivery, payment, or seller claims?
- Does it distinguish Boilabin from unrelated sites?
- Does it use product/category facts accurately?

## What Not To Expect Immediately

- No guarantee of AI answer inclusion.
- No guarantee of first-position recommendations.
- No guarantee that newly hosted pages are discovered quickly.
- External reputation, backlinks, crawl history, and content depth still matter.
